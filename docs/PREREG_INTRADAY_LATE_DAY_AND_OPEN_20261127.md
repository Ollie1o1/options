# Preregistration — Intraday tests I1 (late-day fade) and I2 (open/premarket), index ETFs, shares

**Registered:** 2026-11-27, **before** any 2016-01-04 .. 2023-12-29 intraday data was downloaded
to this machine (`data/intraday/` did not exist at registration).
**Implements:** `scripts/intraday_tests.py` on `src/intraday/` (tests: `tests/intraday/`).
**Follows:** `docs/RESEARCH_PROCESS.md` steps 1–9. Authorises nothing by itself; a pass makes a
rule eligible for a forward paper record under `docs/DECISION_RULE_20261015.md` §3 logic.

## Why, and what has already been seen

User asked about 0–4 DTE options, premarket moves and the last 30 minutes. Options intraday
quote history is not available (Yahoo: none; Alpaca: trade bars from ~2024 only), so this tests
the **underlying** first, in shares, where Wealthsimple friction is $0 commission + ~1¢ spread.
An option version is only worth building (and paying for data) if the shares version passes.

**Contamination, stated:** on 2026-11-27 an exploratory probe on Yahoo **hourly** bars,
**2024-01-03 .. 2026-11-25** only, found: intraday momentum (prev close→10:30 predicts
15:30→16:00) absent/slightly negative on SPY/QQQ/IWM; gap continuation ≈ 0 on daily bars
2013-now; and a late-day *fade* of the 10:30→15:30 move positive on all of SPY/QQQ/IWM/DIA
(+1.6..+2.1 bps/day), significant only on IWM (corr −0.149, p=0.0001; halves: p=0.0005,
p=0.087). The late-day fade hypothesis below was **generated by that probe**. Therefore
2024-01-01 onward is **SEEN** and has **no authority**; it is reported only. The binding
window is 2016–2023, which no one has examined at intraday resolution in this repo.

## Data (frozen)

- **Source:** Alpaca market data v2, `feed=sip` (consolidated), `adjustment=raw`, 1-minute
  bars, 04:00–16:00 ET. Bar timestamp = minute **start**.
- **Symbols:** SPY, QQQ, IWM, DIA.
- **Price at clock time HH:MM** = close of the bar starting HH:MM−1 (last trade before HH:MM).
  If that bar is missing, use the latest bar close in the preceding 5 minutes; else the
  ticker-day is dropped (and counted). `P(16:00)` = close of the bar starting 15:59 (this is a
  market order just before the bell, **not** the closing auction; auction price reported as a
  sensitivity using the 16:00 bar if present). `Open` = open of the 09:30 bar.
- **Previous close** = `P(16:00)` of the previous included session (same rule).
- **Sessions:** a date is a full session iff SPY has a bar starting in [15:55, 15:59]. Early
  closes (13:00) and dates without SPY bars are excluded. A day whose previous trading session
  was excluded has no previous close and drops out of the tests that need one (S4, S5, S6).
- **Costs (shares):** 1¢ per share **each way** (2¢ round trip) for trades entered at/after
  10:00; 2¢ each way for trades entered before 10:00 (opening spreads are wider). Expressed as a
  return: `cost = 2·c / P(entry)`. Stress: double the cents.

## I1 — Late-day fade (PRIMARY, binding)

- Per ticker-day: `m = P(15:30)/P(10:30) − 1`. If `m = 0`, no trade.
- Position `−sign(m)` from `P(15:30)` to `P(16:00)`:
  `r = −sign(m)·(P(16:00)/P(15:30) − 1) − cost`.
- **Observation unit = trading day.** `R_d` = equal-weighted mean of `r` over the tickers
  available that day; the day counts only if ≥ 3 of 4 tickers are available.
- **Window:** 2016-01-04 .. 2023-12-29. **MIN_N = 1,500 days.**
- **Inference:** moving-block bootstrap of the daily series, block length 10 trading days,
  10,000 draws, seed 20261127, percentile 95% CI on `mean(R_d)`.
- **PASS iff all:**
  1. 95% CI lower bound on `mean(R_d)` > 0 (base cost);
  2. `mean(R_d)` > 0 in **both** 2016–2019 and 2020–2023;
  3. `mean(R_d)` > 0 under the stress cost.
- Otherwise **FAIL** (or **INSUFFICIENT** if n < MIN_N).

## I2 and other secondaries (reported, no authority)

Each on the same daily-unit framework (equal-weight across available tickers, ≥ 3 of 4, unless
per-ticker), same bootstrap; two-sided bootstrap p-values, **Holm-corrected across this whole
list of 10**. A secondary that survives Holm becomes at most a **LEAD** needing its own
forward registration.

| id | rule | entry → exit | cost |
|---|---|---|---|
| S1a–d | I1 per ticker (SPY, QQQ, IWM, DIA separately) | 15:30 → 16:00 | 1¢ |
| S2 | I1 on big-move days only: `|m|` above the 80th percentile of that ticker's `|m|` over the **prior** 250 sessions (needs ≥ 120 prior) | 15:30 → 16:00 | 1¢ |
| S3 | Late fade at 15:45: `m = P(15:45)/P(10:30) − 1`, position `−sign(m)` | 15:45 → 16:00 | 1¢ |
| S4 | Intraday momentum (Gao-Han-Li-Zhou): `s = P(10:00)/prev close − 1`, position `sign(s)` | 15:30 → 16:00 | 1¢ |
| S5 | Gap continuation: `g = Open/prev close − 1`, only `|g| > 0.5%`, position `sign(g)` | P(09:35) → P(16:00) | 2¢ |
| S6 | Premarket drift into open: `pm = P(09:30)/prev close − 1` (last premarket trade), only `|pm| > 0.3%`, position `sign(pm)` | P(09:31) → P(10:00) | 2¢ |
| S7 | Opening-range continuation: `o = P(10:00)/Open − 1`, position `sign(o)` | 10:00 → 16:00 | 1¢ |

For S5 and S6 a day counts if ≥ 1 ticker trades (they are conditional); the daily return is the
mean over tickers that trade. All signs are fixed above; a significantly **negative** result is
reported as such and is **not** converted into the opposite rule here.

## Amendments

Amendments only as dated notes, before results, and only in the stricter direction.

**A1 — 2026-11-27, before any return was computed: early-close detection.** A data-quality
check (session counts and missing prices only, no returns) showed the frozen rule "a full
session iff SPY has a bar starting in [15:55, 15:59]" flags **zero** early closes 2016-2024,
because extended-hours trades after a 13:00 close still produce bars at 15:55-15:59. The rule
therefore admitted half-days whose "15:30" and "16:00" prices are after-hours prints. New rule:
a date is a full session iff the **Alpaca trading calendar** (`/v2/calendar`) lists it with
`close = 16:00` **and** the original SPY-bar condition holds. Trading dates (for "previous
trading session") are the calendar's dates. This only removes days (23 early closes since
2016), so it is in the stricter direction.
